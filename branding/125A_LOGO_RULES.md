# 125A GUI Signet Standard

Canonical GUI branding for 125A plugins.

- Use the canonical `125A_Signet_Master.png` as the source.
- Preserve the original signet geometry and internal negative spaces exactly.
- `125` is off-white/light silver.
- The characteristic `A` stroke is red.
- Background is transparent.
- Scale proportionally only. Never redraw, stretch, crop into the signet, or reinterpret it per plugin.
- Derive any small GUI raster from the master, never from a previously downscaled copy.

This is the common branding standard for the 125A concept bundle, including Depthorator.
